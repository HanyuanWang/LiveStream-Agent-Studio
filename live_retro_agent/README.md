# 直播复盘 Agent

这是一个独立的直播流量与话术复盘工具。它接收完整直播视频和巨量百应分钟级流量表，自动转写，再分析话术与流量表现之间的同步关系。

## 输入

必须提供：

- 完整直播视频（MP4、MOV、MKV 或 AVI）
- 巨量百应直播详情页导出的分钟级流量综合趋势 Excel

## 输出

- `流量与话术分析.xlsx`：核心结论、流量波次、逐句话术与流量、分钟流量和原始逐字稿
- `流量与话术分析.docx`：核心结论、强弱波次、可复用原话、话术循环和下一场执行建议
- `处理说明.txt`：输入识别、数据缺口和警告

## 使用

1. 在 LiveAgent Studio 中打开“直播复盘”。
2. 上传同一场直播的视频和巨量百应流量表。
3. 选择输出目录并填写任务名称。
4. 点击“创建并开始”，页面会持续显示进度。
5. 完成后在任务中心打开 Excel、Word 或所在文件夹。

## 分析原则

- 每场重新识别流量强弱时段，不套上一场结论。
- 只研究直播期间的话术与进入、离开、在线、停留、互动、关注、商品曝光及点击之间的关系。
- 不分析 GMV、成交、订单、销量或收入。
- 只研究直播期间的话术与执行，不扩展到短视频、投流或账号运营建议。
- “痛点—塑品—活动机制—卡库存—逼单”用于分析真实循环，不强迫每句话都归入五环节。
- 话术与流量变化只描述同期关系，不伪装成严格因果。
