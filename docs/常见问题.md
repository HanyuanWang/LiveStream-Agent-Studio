# 常见问题

## 双击 EXE 没有打开页面

确认下载的是 GitHub Releases 中的 Windows ZIP，而不是只下载源码。完整发布包应包含 `.runtime`、`LiveAgentStudio.exe` 和四个项目目录。

当前 Beta 启动器尚未使用商业代码签名证书，Windows 可能显示 SmartScreen 提示。请只从项目自己的 GitHub Releases 下载，先用同名 `.sha256` 文件核对压缩包；不要从网盘或转载站获取。无法确认来源时不要运行。

## 页面显示本机 Agent 未连接

重新双击 EXE，等待十几秒后刷新。若仍失败，检查 4173、8785、8765、8775 端口是否被其他程序占用。

## 抖音或蝉妈妈读取失败

点击页面中的登录入口，在专用浏览器窗口完成登录或验证码，再刷新状态。平台权限、会员限制和风控不会被绕过。

## 转写或 OSS 失败

在“设置与连接”中重新填写并实际验证自己的 DashScope Key、OSS AccessKey、Endpoint 和 Bucket。

## 加入录制助手时提示路径不存在

进入 LiveAgent Studio 的“设置与连接”，在“连接快抖直播录制助手”中粘贴本机 EXE 的完整路径并保存。该功能是可选依赖，未配置不会影响其他 Agent。
