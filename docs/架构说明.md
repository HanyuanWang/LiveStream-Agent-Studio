# 架构说明

```text
LiveAgentStudio.exe
  └─ PowerShell 启动器
      ├─ 4173 统一工作台网页
      ├─ 8785 本地网关与任务中心
      ├─ 8765 主播发现服务
      └─ 8775 直播复盘服务

本地网关
  ├─ 直播拆解 Agent
  ├─ 视频编导下载、音轨提取与转写
  ├─ OSS / DashScope 连接验证
  └─ 本地文件与任务管理
```

网页只监听本机端口。浏览器负责界面，本地 Python 服务负责文件、视频和任务处理。浏览器 Profile、数据库、任务文件和生成结果均位于各项目的 `workspace`，该目录被 Git 忽略。
