# 隐私与发布检查清单

- [ ] 仓库中没有任何 `.env` 文件，只保留 `.env.example`。
- [ ] 没有 DashScope API Key、OSS AccessKey ID/Secret、安全令牌。
- [ ] 没有 Cookie、Chrome/Edge Profile、蝉妈妈或抖音登录数据。
- [ ] 没有 `workspace`、数据库、录屏、音频、逐字稿、订单或流量业务文件。
- [ ] 没有开发者姓名、微信、手机号、邮箱或桌面绝对路径。
- [ ] 没有 `node_modules`、Python 缓存、日志和临时构建目录。
- [ ] `.openai/hosting.json` 中的个人项目 ID 没有进入公开包。
- [ ] README 已说明第三方平台权限、云端费用和快抖依赖。
- [ ] GitHub Actions 构建成功，Windows ZIP 解压后可双击启动。
- [ ] 首次公开建议先建 Private 仓库，复查后再切换为 Public。
