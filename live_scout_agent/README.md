# 直播主播发现 Agent

这是现有“直播拆解 Agent”的上游模块。目标流程是：

```text
自然语言定义关注领域
  → 导入蝉妈妈带货达人榜
  → 同领域内部自动评分
  → 候选主播池
  → 生成可编辑Word达人拆解报告
  → 加入快抖直播录制助手
  → 录制完成后进入直播拆解 Agent
```

## 当前可用功能

- 本地网页控制台，不需要输入 Python 命令。
- 用自然语言描述女装、保健品等关注领域。
- 使用已经配置的 Qwen 解析描述；不可用时自动退回本地规则。
- 支持 `.xlsx`、`.xlsm`、`.csv`、`.txt` 榜单。
- 自动识别主播、粉丝、类目、销售额、销量、GPM、UV价值、直播时长、场次、主页链接等常见列名。
- 每个领域独立评分，排除词和粉丝上限作为约束。
- 候选主播通过/排除管理。
- 生成快抖可批量粘贴的“一行一个主页链接”文本文件。
- 通过快抖提供的 `kdlive://` 程序协议自动添加主页链接、启动或停止监控。
- 一键启动本机已经安装的快抖直播录制助手。
- 使用独立Chrome配置保存蝉妈妈登录状态，不接管日常浏览器。
- 蝉妈妈带货达人榜下载完成后自动导入、评分并更新候选池。
- 候选主播可批量生成达人拆解报告，覆盖人设、内容策略、带货策略、粉丝画像、近期异动、优势短板、合作潜力和同行可复用打法。
- 达人拆解会在账号权限允许时读取详情页中的直播记录与商品分析，新增逐场GMV、场均/中位数GMV、最高单场占比、稳定性判断，以及商品名称、细分品类、商品链接、成交均价、商品GMV和GMV占比。
- 页面没有提供逐场或商品级数据时，报告会明确标记“数据不足”，不会把周期总GMV平均分配到各场，也不会让模型猜测商品成交额。

## 最简单的使用方式

1. 双击 `01_启动主播发现Agent.cmd`。
2. 浏览器会自动打开 `http://127.0.0.1:8765`。
3. 在“关注领域”中写一句话，让 Agent 理解并确认。
4. 首次进入“蝉妈妈数据源”，打开专用浏览器并扫码登录。
5. 选择关注领域和日榜/周榜/月榜后点击“从蝉妈妈更新”；Agent会自动进入“达人 → 带货达人榜”、选择对应带货分类并执行正常导出。
6. 下载完成后，Agent自动导入并更新候选主播池。
7. 在“候选主播”中勾选目标达人，点击“生成达人拆解”，下载可编辑 Word 报告。
8. 通过主播后，可继续加入快抖。

启动脚本会把控制台放到后台守护运行：关闭启动窗口不会停止 Agent，服务意外退出后会自动重启。重复双击启动脚本只会打开已有页面，不会重复启动多个服务。需要主动停止时，双击 `04_停止主播发现Agent.cmd`。电脑关机或重启后仍需重新双击一次启动脚本。

后台服务日志位于 `workspace/service`；若页面无法访问，可先重新双击启动脚本，再运行 `02_检查主播发现Agent.cmd`。

## 数据和安全

- 数据库位于 `workspace/live_scout.db`。
- 原始榜单副本位于 `workspace/uploads`。
- 快抖导入名单位于 `workspace/exports`。
- 蝉妈妈独立浏览器配置位于 `workspace/chanmama/profile`。
- 蝉妈妈正常导出的榜单位于 `workspace/chanmama/downloads`。
- 达人拆解报告位于 `workspace/reports`。
- 快抖录制文件由快抖直播录制助手保存在其本地录屏目录。
- Qwen Key 复用相邻 `live_breakdown_agent/.env`，控制台不会显示密钥。
- 不读取日常浏览器的配置、密码、标签页或历史记录。
- 不调用蝉妈妈隐藏接口，不绕过验证码、会员权限或导出限制；只读取用户账号正常可见的达人详情页面和榜单文件。

## 录制管理

当前版本完成了“领域定义 → 蝉妈妈独立登录 → 带货达人榜读取 → 自动导入与评分 → 候选池 → 达人拆解报告 → 快抖监控与录制”的流程。

- 只有通过本 Agent 加入快抖的主播会出现在录制名单中。
- 本页只负责向快抖添加主播以及启动、停止监控。
- 录像不会自动上传、转写或拆解，不会因为录制管理产生 OSS 或模型费用。

蝉妈妈当前页面的榜单路径、带货分类和榜单周期已完成自动点击校准。
